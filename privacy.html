automated_vid

Privacy policy

Last updated 18 October 2026

automated_vid is a personal, non-commercial tool used only by its owner, on the owner's own Google accounts and YouTube channels. It is not offered to anyone else.

Google data it accesses

When its owner signs in with Google, automated_vid may use the YouTube Data API and the YouTube Analytics API to:

  • read the owner's channel details and the owner's own videos, playlists and their public statistics;
  • upload videos to the owner's channels and set or edit their titles, descriptions, playlists, visibility and publish times;
  • read YouTube Analytics reports (views, watch time, traffic sources) for the owner's own channels.

It does not access anyone else's account, and it does not collect personal information about viewers.

How the data is used

Only to publish and manage the owner's own videos and to see how they perform, so the tool can plan new videos. Aggregate performance numbers for the owner's videos (for example view counts) may be included in requests to AI model providers that help plan new videos. No Google user data is sold, used for advertising, or shared for any other purpose.

Storage and security

Sign-in tokens and reports are stored on the owner's own computers and are not published. Tokens are used only to make the API requests listed above.

Removing access

Access can be withdrawn at any time from the Google account's security page: myaccount.google.com/permissions. Stored reports can be deleted by the owner from their computers.

YouTube API Services

automated_vid uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
